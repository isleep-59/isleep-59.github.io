01 / Concept explorer

从“说错了什么”
到“是否用对了视觉证据”

Hallucination 描述输出错误；grounding 与 reasoning 描述证据连接和推导能力。关系幻觉的积累，可以沿着这条证据链继续发展。

错误现象Hallucination

断言是否与图像矛盾，或缺乏支持？

证据连接Grounding

说的是哪个实体，依据图中哪里？

前提 → 结论Reasoning

关系与事实是否被正确组合、使用？

同一个问题，四种行为

教学模拟 · 非模型实测
抽象位置图：同一水平参照系
A
B
C
左横坐标 →右
问题：A 是否在 C 左边？
前提：A 在 B 左边；B 在 C 左边。

“是。A 在 B 左边，B 在 C 左边，因此 A 在 C 左边。”

最终答案正确；解释的前提也正确。

换到“反转关系”，答案应该改变；只换背景，答案应保持。这里用可控规则演示证据依赖，不是在读取模型内部思维。

概念依据：CHAIR、MMRel、MIRAGE。上例仅适用于明确的 left-of 关系，不能把传递性套给 holding、near 等谓词。

Grounding 有两层含义，必须分开

狭义是把文本实体定位到框、掩码或点；广义是让断言受到视觉证据约束。两个框都定位正确，仍可能把主客体角色或动作关系说错。解释正确也不一定忠实反映实际决策。CREG v4 与 vCT/vCCT 分别讨论归因和行为证据的边界。

03 / Benchmark map

换一个任务接口，就换了一种“会不会”

同一个错误关系，可以成为负描述、Y/N 错题、生成幻觉，或多跳推理的错误前提。指标因此不能直接混排。

04 / Mechanisms, not labels

算法正在同一条证据链上相遇

01 / READ识别与绑定

对象、实例、主体 / 客体
Grounding、区域提示

02 / VERIFY读取关系证据

谓词、动作、方向
对比解码、核验器

03 / COMPOSE组合视觉前提

多跳、比较、规则
Grounded CoT、工具

04 / DECIDE输出与校准

选择答案、判断未知
重排、偏好训练

这是一种诊断分解，不意味着每个 VLM 内部有四个独立模块。

2023–24
VCD / OPERA / Woodpecker

从原图 / 扰动图分布、注意力解码，或生成后核验，减少视觉不支持的输出。它们已在试图恢复视觉证据的作用。

2024–25
Visual CoT / Argus / MM-GCoT

定位后重看、对象级视觉上下文与坐标推理训练。给 CoT 加 bbox 或 crop 已有直接先例。Nullu 则从参数编辑处理幻觉倾向。

2025–26
DeFacto / Faithful-MR1 / C3PO

反事实证据训练、视觉关注监督、CoT 压缩与偏好优化。幻觉没有消失，而是进入推理训练和过程评测。

2026
SEER / TTSP / EAGLE / ReGround

角色标记与证据接口、多假设冲突、证据仲裁和选择性重注入。连“分歧时再看一次”也已被覆盖。这些近期预印本是新算法必须面对的强近邻。

不能只换标题：“加入 crop”“加入 verifier”“做反事实＋RL”均不足以单独构成研究 gap。候选新意应具体到：什么关系失败、核验哪条前提、为何同预算能修好更多答案。

05 / Research decision

建议转向：有视觉依据的关系推理

保留关系分类、候选验证、跨问法对齐与校准经验。以算法涨点为目标，让小规模诊断决定算法该改哪里。

第一阶段 · 快速判断

先验证旧 verifier 在新模型上还剩多少收益

  • 固定候选、prompt 和输出解析，迁移到两个现代公开 VLM 家族。
  • 对比原始回答、关系重排、SEER 和同预算整图重答。
  • 分开准确率、召回率与误改正确答案，避免把“更少说 yes”当全面理解提升。

适合作为研究起点；迁移和组合本身不承诺论文新颖性。

推荐候选 · 先冻结模型

把额外观察分配给会改变结论的关系

  • 将任务显式拆成少量实体与关系前提，保留直接回答 fallback。
  • 区分绑定错误与谓词错误；优先核验既不确定、又影响最终答案的关系。
  • 补充对应证据，只更新受影响的后续判断，再用固定 verifier 决定是否改答案。

待验证假设：比随机重看、最低置信度重看和完整重答，更有效地利用相同计算预算。必须对照 ReGround、TTSP、EAGLE；尚未证明新颖性或有效性。

后续 · 有正证据再训练

把可靠修复转成关系支持监督

  • 仅收集经过人工或独立核验的关系支持 / 反例，避免模型自证循环。
  • 先 LoRA / SFT 或偏好训练，和同数据普通答案训练比较。
  • 同时报告直接回答的准确率、跨域迁移和推理成本，确认是否把工具收益固化。

DeFacto / Faithful-MR1 是直接近邻。训练资源充足也不意味着应该先做大规模 RL。

真正需要验证的 gap：在实体绑定与单边关系已被分别检查的条件下，有限的核验预算应分给哪条关系，才能最可靠地改善组合答案？这是具体候选问题，不是已经确认的文献空白。

算法涨点，要扣掉它新制造的错误

假设未更新样本答案不变。拖动三个参数，观察净收益。数值完全是教学假设，不是实验或预测。

“修对”与“改错”互斥，合计不超过 100%。

全体样本的 Accuracy 变化
+3.60 pp

30% × (20% − 8%) = +3.60 个百分点

只报告成功修复案例，会漏掉误改代价。选择性核验也必须计入定位、视觉编码、所有候选评分与生成成本。

值得继续

先做有停止条件的 pilot

  • 200–400 个分层自然样本，另加可核验组合题。
  • Oracle 框 / 关系只作独立诊断，不混入主结果。
  • 固定预算比较修对和改错，再扩到两个家族、两个分布。
  • 按原始图像划分与计算成对置信区间，检查共享图像泄漏。
应该改向

这些结果不支持扩成大课题

  • 收益只有旧 LLaVA 才有，现代强模型上消失。
  • 同预算 SEER / 整图重答已解释全部涨点。
  • 只有 oracle 定位才能改善，预测定位反而误改。
  • 只是阈值和 recall 权衡，却声称提升了整体 reasoning。
为什么暂不建议直接转向通用数学、视频或 3D reasoning？

这些方向需要新的数据、几何或时序能力，与你的关系评测与验证器积累距离更远。先确定瓶颈：若主要看错，优先 perception / grounding；若前提对而组合错，再做关系推理。可以转向，但应带着一个可测的机制问题进入，而不是只追热点标签。
